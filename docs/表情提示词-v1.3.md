# 眉姐姐 · 新表情提示词（v1.3）

统一要求（每条都带上）：

- 参考图只用 `assets/pets/pet001/avatar.png`（同一只猫的身份母版），保持虎斑英短混血、3 岁、棕黑虎斑纹、黄绿眼睛、粉色鼻头、白下巴。
- 构图：正面偏 3/4，整张脸完整入画，眼睛在画面上三分之一附近，头顶留一点空白，下方留出胸口。
- 画风与光照：和已有表情一致——柔和侧逆光、暖奶油色调、细腻毛发、背景纯白（方便本地抠图转透明底）。
- 输出：1:1 方图，2048×2048，不要文字、不要水印、不要多余道具（除非该表情需要）。
- 表情只改脸和五官，身体姿态、毛色、花纹位置不要变。

## 1. 吃饭张嘴（核心新增·不出现食物）

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她正张大嘴准备吃东西：嘴巴张开成一个圆润的小口，能看到一点粉色的口腔内部和门牙，舌头微微抬起但不出画；眼睛亮亮的、微微睁大，眉毛（胡须垫上方）轻轻上扬，表现出期待又满足的样子。画面里**不要出现任何食物、碗、勺子、手或餐具**，只有猫自己张嘴。胡须自然张开，耳朵朝前，暖光从右上方打过来，毛发边缘有柔和的轮廓光。

## 2. 点头（认真答应）

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她正在认真点头答应：下巴微微向下收，头部略低，眼睛半闭成一条温柔的眼缝，嘴角向上带一点点笑，耳朵向前倾，胡须放松下垂。整体是“好呀，听你的”那种乖巧感，不要张嘴、不要露牙。

## 3. 眨眼（wink）

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她俏皮地眨一只眼：左眼睁得圆圆的看镜头，右眼完全闭成一条弧线，嘴角一侧微微上扬，耳朵放松，鼻头粉色高光。可爱、调皮，不夸张不诡异。

## 4. 鼓腮生气

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她鼓起两颊、嘴巴抿成一条小小的“人”字线，眼睛瞪圆但眉毛向下压，耳朵微微向后，胡须向前翘。是“哼，不理你了”的软脾气，不要凶、不要龇牙。

## 5. 捂脸害羞

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她用两只前爪轻轻挡住半张脸，只露出一双眼睛从爪子上面偷看镜头，眼睛弯弯的，脸颊有一点粉。爪子要毛茸茸、比例正常，不要挡住眼睛。

## 6. 伸懒腰打哈欠

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她正在伸懒腰打哈欠：嘴张成一个舒服的 O 形，眼睛闭成两条弯线，头微微后仰，两只前爪向前伸直，肩膀拉开。慵懒、放松，不要露出过多牙齿。

## 7. 叼着小鱼干（可选·这张允许有道具）

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她嘴里叼着一条小小的橙色小鱼干，鱼干只露出两端，眼睛得意地眯起来，耳朵朝前，胡须因为叼东西微微张开。除小鱼干外不要别的道具。

## 8. 抬头看你（想让抱）

> 同一只虎斑英短混血猫的正面半身像，纯白背景。她微微仰起头看着镜头，眼睛又大又亮、瞳孔放大，嘴巴闭着但嘴角向下一点点显得委屈，耳朵向前、一只微微下垂，胡须下垂。是“抱抱我嘛”的眼神。

## 落地流程（生成后）

1. 每张下载到 `assets/pets/pet001/_raw/`，文件名：`eat.png / nod.png / wink.png / pout.png / shyhide.png / yawn2.png / fishmouth.png / look-up.png`。
2. 跑 `python tools/make_expressions.py`：白底抠图 → 统一脚底对齐 → 512×512 透明 PNG。
3. 在 `assets/config/game-config.js` 的 `states` 里加键（例如 `eat`、`nod`、`wink`、`pout`、`shyhide`、`look`），指到新文件名。
4. 想让它“点头”，把 `nod` 配一个上下小幅摆动的 CSS 动画（或 `pet.js` 里加一次 0.4s 的点头 action）即可，不需要逐帧。
