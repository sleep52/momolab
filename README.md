# Momolab · 眉姐姐的专属世界

为一只宠物定制的互动冒险游戏。纯静态站点，无需构建、无需后端，双击就能玩。

![单页游戏](index.html)

## 怎么打开

**推荐：** 双击 `启动游戏.bat`，会起一个本地服务并自动打开浏览器（拍照和下载功能需要它）。

**也可以：** 直接双击 `index.html`。除了「拍照」保存图片可能被浏览器同源策略拦住，其余功能都能用。

手动起服务：

```
cd momolab
python -m http.server 8010
# 浏览器打开 http://127.0.0.1:8010
```

## 能玩什么

| 区域 | 内容 |
|---|---|
| 宠物小屋 | 壁炉休息、书架旧相册、毛线球、圆窗发呆 |
| 花园 | 浇水让花圃开花、采郁金香、追蝴蝶、从藤蔓拱门进森林 |
| 森林 | 开宝箱、采蘑菇、捉萤火、按藏宝图线索寻宝 |
| 湖泊 | 完成 2 款小游戏解锁；鱼群、睡莲、贝壳、码头小游戏 |
| 秘密区域 | 任意五款小游戏通关后解锁；记忆水晶、爪印徽章、月光花 |
| 换装间 | 头部 / 颈部 / 身体三槽位、8 件装饰、点穿或把衣服拖到猫身上、随机搭一套、全部摘下 |
| 默契测试 | 八道关于她的小问题，按答题结果给分 |

互动：摸摸 / 喂食 / 陪玩 / 呼唤 / 休息 / 拍照。17 个整脸表情 + 程序化动作 + 粒子反馈。

小游戏（六款，都能反复玩，成绩会记住）：寻找零食（限时找物）、接住玩具（Canvas 物理 + 连击）、记忆翻牌（3D 翻牌）、森林寻宝（三段线索）、小猫快跑（三条跑道的地铁跑酷：换道 / 起跳 / 小鱼干连击 / 四条命 + 每 80 米补命）、小猫钓鱼（力度抛竿 + 浮标下沉窗口收竿）。

系统：每日任务与探索任务、四项成长属性、**每天一换的心情与“她今天喜欢的衣服”**、收藏图鉴与佩戴装饰、相册（下载 / 分享）、设置与重新开始。

三条里程碑：集满 8 种收藏解锁「奶油蝴蝶结」；完成任意 2 款小游戏解锁湖泊（首次到湖边获得「格纹围巾」）；任意五款小游戏通关解锁秘境，六款各玩一次拿到「猫耳贝雷帽」。

## 换成另一只宠物（不用改逻辑）

1. 把新宠物的表情立绘放进 `assets/pets/pet001/`，保持同一机位、同一比例；
2. 把新场景图放进 `assets/img/scenes/`；
3. 改 `assets/config/game-config.js` 里的 `petName / petBreed / petIntro / petCharacterAssets / sceneAssets / areas / items / tasks / branding`；
4. 刷新即生效。品牌署名在 `branding.showCredit` 一处开关。

游戏核心逻辑全部从配置读取，换素材、换文案、换主题都不需要改 `js/` 下的代码。

## 存档

存在浏览器 `localStorage`：

- `momolab.save.v1` 游戏进度、属性、收藏、任务、成绩
- `momolab.album.v1` 相册（保留最近 12 张，压缩后存储）

清浏览器数据会一起清掉。设置页有「重新开始」。

## 已知边界

- 相册写入受 localStorage 容量限制，只保留最近 12 张。
- 拍照导出需要 `http://` 环境（`启动游戏.bat` 已经处理）；`file://` 下会提示改用本地服务。
- 角色动作为「统一机位立绘 + 程序化动作」，如需逐帧行走序列，把 `petCharacterAssets.states` 换成帧数组即可。
- 装饰分三层叠：身体 → 颈部/身体装饰 → 头部裁切层 → 头部装饰。头部裁切图在 `assets/pets/pet001/layers/`，由 `tools/split_pet_head.py` 生成，所以围巾上缘会被下巴压住。`n- 装饰贴图用 `tools/fit_garments.py` 预处理过（`*_fit.png`）：贝雷帽原图自带猫耳朵，脚本按帽体轮廓切掉，只留帽壳；所有贴图边缘都烘了一圈 AO 暗边。`n- 落点在 `game-config.js` 每件物品的 `overlay`（x/y/w 相对猫立绘的百分比），换姿势或换猫要重新校准一次。
- 浏览器会缓存 `game-config.js`，改了配置看不到变化时用 `python tools/devserver.py` 起服务（带 `no-store`），再普通刷新即可。

## 这一版新加的东西

- **猫可以拖**：按住她就拖走，拖动中表情会换，松手靠近热点会说一句应景的话，双击回到原位。
- **衣服能拖到猫身上**：换装间的卡片直接拖到预览猫，落点判定 + 高亮，松手就穿上；点一下也能穿。
- **她今天喜欢的衣服**：按日期哈希出当天心情（黏人 / 贪吃 / 犯困 / 得意 / 好奇），每种心情有 2 件偏爱的衣服，卡片右上角有「今天喜欢」角标；当天穿中一次，给亲密 +2、星星 +6。
- **换装预览按心情换表情**：开心 / 困 / 害羞 / 得意 / 好奇。
- **小游戏里她都出镜**：找零食、翻牌、寻宝有实时表情徽标，接玩具是猫蹲在篮子后接，快跑和钓鱼是 Canvas 里直接画的她。
- **小猫快跑**：三条跑道的伪 3D 跑酷，←→ / A D 换道，↑ / 空格 / W 起跳，触屏按滑动方向判定；小鱼干 +12 米和连击，撞到掉命并短暂无敌，四条命 + 每 80 米补一条，300 米通关。
- **小猫钓鱼**：60 秒钓 5 条，力度条决定抛多远、鱼多大；浮标沉下去的窗口内收竿才算钓上，早了就是跑鱼。
